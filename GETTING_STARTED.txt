🚀 QUICK START (5 Minutes):

   1. Install Dependencies
      $ npm install

   2. Set Up API Key
      $ cp .env.example .env
      # Edit .env and add your ANTHROPIC_API_KEY

   3. Test the System
      $ npm run editor:research
      
   4. Generate First Article
      $ npm run workflow:daily

   5. Check Output
      $ ls content/articles/

🤖 THE THREE AGENTS:

   📝 Editor Agent
      - Researches Canadian news
      - Writes analysis articles (800-1500 words)
      - Provides data for visualizations
      Commands: npm run editor:research | editor:write

   💻 Developer Agent  
      - Builds website features
      - Implements data visualizations
      - Handles deployment
      Commands: node agents/developer/setup.js "task"

   🔄 Workflow Coordinator
      - Orchestrates agent collaboration
      - Manages daily schedule
      - Handles publishing
      Commands: npm run workflow:daily | workflow:publish
